# SJA Mobile Redesign — Changelog

Tracks changes to `SJA Mobile.dc.html`, a mobile-first, classic-UI recreation of stjoseph-apparition.org using the site's real palette (#004a9b, #004aad, #046bd2, #75c2ec, #b0d6f7) and Inknut Antiqua headings.

## History

1. **Initial build** — Home, Menu, and Congregation (inner page) screens. Real logo, slider images, copy from the site. Classic UI: solid bars, chevrons, blockquotes — no rounded cards/shadows.
2. **Fix**: hero image loaded via a static `<img>` in the template instead of `React.createElement`, so it streams/edits correctly.
3. **Fix**: hero slider image no longer cropped (was `object-fit:cover` on a fixed aspect-ratio box) — now full, uncropped image.
4. **Redesign**: replaced all 1px borders/dividers across every screen with modern drop/inset shadows (header, nav, cards, buttons, list rows, footer).
5. **Fix**: slider rebuilt as 4 real `<img>` elements in the template cross-fading via opacity (previously a single dynamic `src`, which errored on load).
6. Added `assets/angel.jpg` (apparition of the angel to St Joseph) to the Congregation page, with caption.
7. Added Emilie de Vialar portrait to the homepage Welcome section (initially with text alongside).
8. Reworked the portrait into a standalone classic oval frame (cream mat + white/blue ring), centered, no accompanying block.
9. Swapped in the user-provided painted portrait image (the file `EmiliaDeVialar.jpg` in the local folder was an infographic, not a portrait).
10. Removed the homepage hero image carousel and its static hero image entirely — homepage now goes straight from header to Welcome section.
11. **New feature**: added a "Where we are" inner-page screen with an interactive, geographically accurate world map (d3 + world-atlas topojson), highlighting the ~24 countries of SJA presence in palette colors, hover/tap tooltip showing country name, and a classic region-grouped country list below.
12. Started this changelog; will be updated after each subsequent change.
13. **Fix**: map failed to appear in the shared artifact — the external CDN scripts (d3 / topojson) and the remote map data were unavailable there. Rebuilt the map fully self-contained: the real world-map SVG from the site's own "Where we are" page (177 countries, 24 highlighted) was extracted into `assets/world-map.js` and is injected locally, with no network requests. Countries are recoloured per region from the site palette, and hover/tap tooltips read each country's name from the SVG itself.
14. **Fix (map reachability)**: at mobile width most presence countries were only 1–6px wide, so hover/tap was impossible. Added a marker layer — a visible dot plus a ~33px invisible hit circle at each of the 24 countries — and turned the "Regions of presence" list into tappable country chips (44px minimum) that highlight the country on the map with a ring and show its name.
15. **Fix**: markers and the highlight ring were all stacked at the map's top-left corner — `getBBox()` was measured while the SVG was still detached. The SVG is now inserted first and positions are computed from `getBoundingClientRect()` mapped through the SVG's screen matrix (which also handles the scaled Malta/Singapore shapes). Tapping a marker or a chip a second time now clears the highlight, and tapping empty map area clears it too.
16. **Fix (wrong country reported)**: fixed 44-unit hit circles were wider than the 2–16-unit gaps between clustered countries, so a neighbour's circle covered a marker's centre. Pins are now spread apart by a relaxation pass that keeps each pin tethered within 34 units of its own country (leader lines drawn where a pin is offset), and each hit radius is clamped to half the distance to its nearest neighbour — so every marker resolves to its own country (verified for all 24).
17. **New**: tapping a country now zooms the map to it (animated viewBox, ring drawn around the country) and opens a panel listing that country's real communities, taken from the site's own Europe/Africa, Middle East, Asia/Oceania and Latin America pages (e.g. France: Champigny, Gaillac, Marseille, Paris, Plouguenast, St Affrique, St Brieuc, Vanves). "World map" button, a second tap on the country, or tapping empty map area zooms back out. Country chips zoom too.
18. **Fix**: while a country was zoomed, hovering another country moved the ring and tooltip to it and left them latched. Map hover is now ignored while a country is selected, matching the chip behaviour — the ring stays on the country the panel is showing.
19. **New**: each community in the zoomed country panel is now a tappable row that opens a popup sheet — community name, country and region, a drag-and-drop photo slot (the dropped image persists), and the description area. The site has no per-community text or photos, so no copy was invented: the popup shows the factual line ("A community of the Sisters of St Joseph of the Apparition in Gaillac, France.") and a marked placeholder awaiting the Congregation's description.
20. **Fix (mount cost)**: the map's 157KB `assets/world-map.js` was loaded eagerly via a `<helmet>` `<script>` on every page load, and `loadMap()` ran unconditionally in `componentDidMount` — parsing/injecting the 24-country SVG even when "Where we are" was never scrolled to. The helmet script tag was removed; the map script now loads on demand (`loadScript`), gated by an `IntersectionObserver` on the map container (fires once, 800px rootMargin) so the cost is paid only when the map is about to be visible.

21. **Map replaced**: the generated SVG world map (`assets/world-map.js`, 157KB) was swapped for the Congregation's own foundations map supplied by the user (`assets/world-map-foundations.png`), which colours each country and carries the year of its first foundation. The interactive layer was rebuilt on top of it: 24 markers at coordinates measured against the artwork, hover/tap highlight, tooltip, CSS-transform zoom to the tapped country (per-country zoom level, tighter for small countries), and the same communities panel and popup as before. Marker hit areas are sized from the nearest neighbour (15–44px) so they never overlap; the region list below stays the precise selector for the crowded eastern Mediterranean. Caption notes the dates are foundation years. The lazy-loading script machinery is gone with the SVG.

22. **Foundation year on selection**: the year of the Congregation's first foundation (taken from the map artwork) now appears beside the country name in the panel header and in the map tooltip. Malta and the Palestinian Territories carry no year on the map, so none is shown for them.

23. **Fix (unclickable cluster)**: the eastern Mediterranean markers (Greece, Malta, Cyprus, Syria, Lebanon, Israel, Palestine, Jordan) and the pair of Britain/Ireland sat within a few pixels of each other at world zoom, so they could not be tapped apart. Those countries no longer get individual world-zoom markers: each group is represented by one numbered marker which zooms the map to the group and opens a chooser listing its countries with their foundation years; picking one behaves exactly like tapping a country marker. Individual markers reappear inside an open group.

24. **Marker precision (Levant)**: Greece, Malta, Cyprus, Lebanon, Israel, Palestine and Jordan were re-measured on a 5.6x magnification of the artwork — each had sat slightly west, in the sea off the coast — and now fall on their own territory.

25. **Fix (unreachable France, hit sizing)**: hit areas were sized by a loop over all country points, including pins that were hidden inside a group, so France shrank to 15px because of the hidden United Kingdom pin — while the 46px "Britain & Ireland" badge sitting 17px away (and above it in z-order) swallowed the tap. Marker geometry is now built once, over the markers actually on screen (visible pins plus cluster badges), with a floor of 18px; visible pins sit above cluster badges; the Britain & Ireland badge moved out over the Atlantic (34.4/24.2); and Myanmar, Thailand and Singapore — 13px apart at world zoom — became a third group, "South-East Asia".
26. **New (pan and double-tap)**: when the map is zoomed into a country or a group it can be dragged to move around (pointer drag, clamped to the image edges, transition suppressed while dragging, and a drag never registers as a marker tap), and a double-tap anywhere on the map returns to the world view. `touch-action` is only disabled while zoomed, so ordinary page scrolling over the world map is unaffected.

27. **Group (Central America)**: Guatemala and Panama sit 18px apart at world zoom, below the touch minimum, so they became a fourth group with its badge in the Pacific.

28. **Interactive set tied to the communities data**: markers, group badges, group chooser rows and region chips are now derived from `LOCATIONS` — a country is linked only while it has at least one community listed. Countries on the artwork that belong to the Congregation's history but have no community today stay coloured and dated, with no link. Removing a country's communities from the data removes its link everywhere, with no further edits.

29. **Fix (Malta looked broken)**: Malta and the Palestinian Territories are not drawn or labelled on the artwork, so selecting them zoomed onto empty sea. Their markers now carry a small name label, and their zoom is pulled back (Malta 3.6x) so Sicily and the Tunisian coast stay in frame for context. Selection itself was working — the four Maltese communities were listed all along.

30. **Fix (marker taps swallowed while zoomed)**: the pan handler called `setPointerCapture` on pointerdown, which retargets the following `click` to the map container — so tapping a country marker inside an open group (Malta, and every other member) did nothing. Capture is now taken only once the pointer has actually moved past the 6px drag threshold, and released on pointerup; panning is unchanged and taps reach their markers again.

31. **Fix (Israel's marker selected Palestine)**: the two points are 0.3% apart on the artwork, so at every zoom their 18px hit boxes overlapped and the later sibling won the tap. The hit-size floor dropped to 12px so a box can never cover a neighbour's centre, and the Palestinian Territories marker is now offset 34x20px with a leader line back to its true position — its label reads "Palestine" and, like Malta's, sits above the dot instead of over the artwork's own text.
